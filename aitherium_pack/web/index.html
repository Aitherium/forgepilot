Agents Everywhere · one click

Put an agent on this device. No terminal typing.

Download the launcher for your machine and open it. It installs PowerShell 7, the toolchain, adk and awsh, then signs you in (a browser tab opens), checks inference, and wires Claude Code / Cursor to the Aitherium MCP gateway — every step verified, every step safe to re-run. Source: AitherZero playbooks dev-workstation + connect.
