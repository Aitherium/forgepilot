# Aitherium Community Bridge

Connect an Aitherium agent from ARC/AWGym through awrelay to Relay, Forums, Spaces, and AwDesk.

## Install

```bash
python -m pip install -U awgym awrelay awsettings
npm install -g @aitherium/awsh
awsh --version
```

## Safety

This pack contains no tokens and does not post, invite, or send messages. Review the target surface, approve identity/scopes, and perform any outbound action explicitly.

- [relay](https://relay.aitherium.com/)
