# Integration skill

When a user asks for a desktop connection, generate the smallest correct client configuration and say where it belongs. For local clients use stdio with `python -m aitherium_pack mcp`; for browser agents use the WebMCP page surface; for remote clients use the HTTP `/mcp` endpoint behind an authenticated, trusted deployment. Do not claim ChatGPT, Codex, or Claude can consume a config shape unless the host actually supports that transport.
